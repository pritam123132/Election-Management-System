🗳️ Election Management System

📌 Project Overview

The Election Management System is a desktop-based application developed using Java Swing. It provides a simple and user-friendly interface for managing election-related activities, including candidate management, viewing election results, and password management.

The project is designed to demonstrate Java GUI development, event handling, and application management.

🚀 Features

- Admin Login: Secure login interface for administrators.
- User Login: Separate login interface for users.
- Dashboard: Easy-to-use dashboard for accessing different modules.
- Candidate Management: Manage election candidates.
- Result Management: View election results.
- Reset Password: Change or reset login credentials.
- GUI Interface: Interactive desktop application built with Java Swing.

🛠️ Technologies Used

- Programming Language: Java
- GUI Framework: Java Swing
- IDE: IntelliJ IDEA
- Image Resources: JPEG / PNG

⚙️ Installation and Setup

Prerequisites

- Java JDK (JDK 8 or later)
- IntelliJ IDEA
- Git (optional)

Steps to Run

1. Clone the repository:
   
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

2. Open IntelliJ IDEA.

3. Select File → Open and choose the downloaded project folder.

4. Make sure the JDK is configured.

5. Locate "ElectionLogin.java".

6. Run the "ElectionLogin.java" file.

🖥️ Application Modules

1. Login Module

Provides the login interface for administrators and users.

2. Dashboard Module

Provides navigation to the main election management features.

3. Candidate Module

4. Result Module
